description: Deep audit — verify what the project claims against what it actually is, and propose a numbered list of actions.

Open [../skills/project-intent/references/audit.md](../skills/project-intent/references/audit.md)
of the `project-intent` skill and follow it.

Judgement, not mechanics: do the documents still describe the code, do they contradict each
other, is the git history and branch state clean.

**Change nothing.** The output is a numbered list of proposed actions for the user to pick
from.

`$ARGUMENTS`, when present, restricts the audit to one domain.
